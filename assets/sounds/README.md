# Audio Assets

Place your breathing sound files here:
- `inhale.mp3` - Gentle sound for inhale phase
- `exhale.mp3` - Gentle sound for exhale phase

These sounds are optional but will enhance the user experience.

You can find free calming sounds from:
- freesound.org
- YouTube Audio Library
- zapsplat.com

Make sure to use soft, calming tones that match the meditative nature of the app.
